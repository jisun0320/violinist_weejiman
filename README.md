# Jiman Wee — Violinist Portfolio

바이올리니스트 위지만(Jiman Wee) 영문 포트폴리오 홈페이지입니다.
모든 이미지가 내장된 단일 파일(`index.html`)이라 별도 자산 없이 그대로 동작합니다.

## GitHub Pages로 공개하는 방법

### 방법 A — 웹에서 업로드 (가장 쉬움)
1. https://github.com 로그인 → 우측 상단 **＋** → **New repository**
2. Repository name에 예: `jimanwee` 입력, **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 클릭
4. 이 폴더의 `index.html` (그리고 `.nojekyll`) 파일을 끌어다 놓고 **Commit changes**
5. 상단 **Settings** → 왼쪽 **Pages** → **Branch**를 `main` / `/(root)`으로 지정 → **Save**
6. 1~2분 뒤 `https://<사용자이름>.github.io/jimanwee/` 주소로 공개됩니다.

### 방법 B — 사용자 대표 주소로 쓰기
저장소 이름을 `<사용자이름>.github.io` 로 만들면 주소가
`https://<사용자이름>.github.io/` 가 됩니다 (index.html을 root에 두면 됨).

## 파일
- `index.html` — 웹사이트 본체 (이미지 포함)
- `.nojekyll` — GitHub Pages가 파일을 그대로 서빙하도록 하는 빈 파일
